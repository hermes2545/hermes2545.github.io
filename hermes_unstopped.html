① Mid-turn Redirection

ไม่ต้อง Stop → Explain → Restart

ถ้า Hermes เริ่มไปผิดทาง ให้พิมพ์ correction ขณะมันกำลังทำงาน ระบบจะรวมคำแนะนำใหม่เข้ากับงานเดิมแล้วเดินต่อ

กำลังทำงาน→พิมพ์ Correction→ปรับทิศ + ทำต่อ
② Voice Interaction

Agent อยู่บน Server ก็ “คุย” ได้

ในตัวอย่าง ผู้ใช้ส่ง voice note ผ่าน WhatsApp แล้ว Hermes ส่งคำตอบกลับมาเป็น voice note โดย workflow ไม่ต้องอาศัยคีย์บอร์ด

🎙 Voice note→Hermes→🔊 Voice reply
③ Grounded Citations

จาก “ตอบมั่นใจ” → “ตามรอยหลักฐานได้”

ผลวิจัยมีแหล่งที่มาให้ตรวจย้อนกลับ และมี Fact-checking mode สำหรับเอกสาร รายงาน ข้อเสนอ หรือ brief เพื่อแยกว่าอะไรตรวจสอบได้ อะไรไม่ตรง และอะไรยังยืนยันไม่ได้

Claim→Evidence→Source link→Fact-check
④ Terminal Workflow

Bang Mode + /context + /init

คำสั่งที่เคยต้องผ่าน model round-trip ถูกทำให้สั้นลง และมี shortcut ช่วยมองเห็นสิ่งที่กิน Context Window รวมถึงสร้างไฟล์ project context เริ่มต้นอัตโนมัติ

วิดีโอนี้สรุปการอัปเดตครั้งสำคัญของ Hermes AI Agent (เวอร์ชัน 0.20) ซึ่งช่วยให้การใช้งานมีประสิทธิภาพและอิสระมากขึ้น โดยมีหัวข้อสำคัญดังนี้ครับ:

  1. การแก้ไขคำสั่งระหว่างทำงาน (Mid-turn Redirection): คุณสามารถพิมพ์แก้ไขคำสั่งหรือทิศทางการทำงานของ Hermes ได้ทันทีในขณะที่มันกำลังประมวลผล โดยที่งานเดิมที่ทำเสร็จแล้วจะไม่หายไป (03:31 - 04:28)
  2. การใช้งานผ่านระบบเสียง (Voice Interaction): Hermes สามารถรับคำสั่งด้วยเสียงและโต้ตอบกลับมาเป็นเสียงได้ผ่านช่องทางต่างๆ เช่น WhatsApp ทำให้ไม่ต้องพิมพ์ข้อความ (04:49 - 06:06)
  3. ระบบอ้างอิงและตรวจสอบข้อเท็จจริง (Grounded Citations): เพิ่มความน่าเชื่อถือด้วยการแสดงแหล่งที่มาของข้อมูล (Citations) พร้อมลิงก์ไปยังต้นฉบับ และมีโหมดตรวจสอบความถูกต้องของเอกสาร (Fact-checking) (06:44 - 08:04)
  4. คำสั่ง Terminal ใหม่ (Bang Mode & Shortcuts): เพิ่มประสิทธิภาพการทำงานผ่านคำสั่งลัด เช่น:
    • Bang Mode (!): รันคำสั่ง Shell ได้ทันทีโดยไม่เปลือง Token
    • /context: ตรวจสอบสิ่งที่อยู่ใน Context Window
    • /init: สแกนโปรเจกต์และสร้างไฟล์ agent.md ให้อัตโนมัติ (08:10 - 10:48)
  5. ความสามารถอื่นๆ เพิ่มเติม: รองรับการสื่อสารระหว่าง Agent (A2A Protocol), การขยายขีดจำกัดของขั้นตอนการทำงานจาก 90 เป็น 500 ขั้นตอน, และการรองรับไฟล์ Office (Word, Excel, PDF) ได้ดียิ่งขึ้น (10:49 - 12:55)
