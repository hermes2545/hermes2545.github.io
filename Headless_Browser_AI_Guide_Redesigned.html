อ่านภาพนี้ยังไงดี

ถ้าหัวหน้าจะเลือกใช้งานจริง หนูแนะนำให้ดูตาม 3 คำถามนี้ก่อนค่ะ

1) ถ้าเว็บกันบอทโหด

อย่าดูแค่ว่า script รันได้ไหม ต้องดูด้วยว่ามีร่องรอย CDP, webdriver, headless หรือเปล่าค่ะ

2) ถ้าให้ AI ใช้เอง

ตัวที่ agent-friendly จะสำคัญมาก เช่น action ที่เสถียร, debug ง่าย, และมี ecosystem รองรับค่ะ

3) ถ้าจะดูแลงานยาว ๆ

ของที่ stealth มาก แต่ ecosystem เล็ก อาจดูแลยากกว่า stack หลักที่มี community ใหญ่ค่ะ

สรุปแต่ละตัวแบบเข้าใจง่าย

คะแนนด้านล่างเป็น “Hermes practical summary” จากข้อมูล repo/README ที่ตรวจมา ไม่ใช่ benchmark ทางวิทยาศาสตร์ค่ะ

เลือกชื่อเครื่องมือเพื่อดูรายละเอียด

สรุปเร็ว ถ้าจะเลือกใช้งานจริง

ดูคำแนะนำแบบรวบรัดตามโจทย์ใช้งาน แล้วเทียบปัจจัย stealth ที่เกี่ยวข้องต่อท้าย

โจทย์ ตัวที่เหมาะ เหตุผลแบบบ้าน ๆ
เน้นโดน block น้อยสุด nodriver ลดร่องรอย webdriver/Selenium ชัดที่สุดในกลุ่มยอดนิยมที่ดูมา
เน้น AI ใช้งานจริงระยะยาว Playwright + rebrowser patches ตัวหลักเก่งมากเรื่อง agent + มี patch ช่วยลด automation leaks
เน้น workflow agent สำเร็จรูป browser-use / Stagehand ใช้ง่ายสำหรับ agent แต่ถ้าเจอเว็บกันหนักก็ยังต้องเสริมฐาน stealth
มี Selenium เดิมอยู่แล้ว undetected-chromedriver ย้ายงานเดิมต่อได้ง่าย แต่ไม่ใช่คำตอบที่ดีที่สุดสำหรับอนาคต AI stack
💡 หลักสำคัญ: stealth ไม่ได้มาจาก browser อย่างเดียว • proxy / IP reputation • fingerprint coherence • human-like behavior • timing & flow ของการใช้งาน
