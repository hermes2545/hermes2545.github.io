Hero Section

Main Content (Main)

พื้นที่เนื้อหาหลักของหน้า อยู่ระหว่าง Header กับ Footer ใน HTML ใช้แท็ก <main>

Section

"ท่อน" หรือบล็อกเนื้อหา 1 เรื่องในหน้า เช่น ส่วนแนะนำสินค้า ส่วนรีวิว — หน้าเว็บคือหลาย section ต่อกัน

Container / Wrapper

กล่องครอบเนื้อหาเพื่อคุมความกว้างให้อยู่กึ่งกลาง ไม่ให้ยืดเต็มจอบนหน้าจอใหญ่

Sidebar

แถบด้านข้าง (ซ้ายหรือขวา) ใส่เมนูย่อย, filter หรือ widget — ใช้บ่อยมากใน dashboard และระบบหลังบ้าน

Footer

ส่วนท้ายล่างสุดของหน้า ใส่ลิงก์รวม, ที่อยู่ติดต่อ, social และข้อความลิขสิทธิ์ (copyright)

Grid / Column / Row

ระบบจัดวางแบบตาราง แบ่งหน้าเป็นแถว (row) และคอลัมน์ (column) เพื่อให้องค์ประกอบเรียงเป็นระเบียบ

Sticky Header / Fixed Header

Header ที่ "เกาะ" ขอบบนจอตลอดแม้เลื่อนหน้าลงไป เพื่อให้เมนูใช้ได้ทุกเวลา

Divider / Separator

เส้นคั่นแบ่งเนื้อหาออกเป็นส่วน ๆ ใน HTML คือแท็ก <hr>

Whitespace (Padding / Margin)

พื้นที่ว่างรอบองค์ประกอบ — padding คือช่องไฟด้านใน, margin คือระยะห่างด้านนอก

พื้นที่ที่จอมองเห็น

Viewport

พื้นที่หน้าจอที่มองเห็นเว็บได้จริงในขณะนั้น — มือถือกับ desktop มี viewport ต่างกัน

Responsive Design / Breakpoint

การออกแบบให้ layout ปรับตัวตามขนาดจอ — จุดที่ layout เปลี่ยน (เช่นที่ 768px) เรียกว่า breakpoint
