Chapter 01

1. Purpose and Mission

Use this skill when you want an AI system to turn a podcast script, narration, transcript, essay, documentary script, educational script, or business explainer into a sequence of image-generation prompts.

The goal is not to create random beautiful images. The goal is to create a visual storytelling system:

Narration/transcript → story beats → visual metaphors → shot list → consistent image prompts → generated image sequence → video timeline

Every image must answer one question:

What idea in the narration does this visual help the viewer understand?

The default visual direction is a hand-drawn editorial illustration look: calm, intelligent, documentary-like, muted colors, clean ink outlines, one idea per image. The style is a configurable parameter — the user may keep the default, pick another numbered preset, combine presets, or supply a fully custom style bible. The workflow never changes when the style changes.

Chapter 02

2. When to Use

Use this skill when the user wants to:

  • Generate images for a podcast video.
  • Create a YouTube explainer video with voiceover and visuals.
  • Convert a narration script or transcript into visual scenes.
  • Create a consistent set of AI image prompts.
  • Build a storyboard for business, economics, history, science, biography, politics, technology, or educational content.
  • Produce still images that can later be animated with pan, zoom, parallax, or simple transitions.
  • Give another AI system clear instructions for producing a full visual package.

Do not use this skill when the user only wants:

  • A single thumbnail image.
  • A logo.
  • A cinematic video prompt only.
  • A fully animated scene without first creating a storyboard.
  • Random decorative background images unrelated to the narration.

Chapter 03

3. Core Principle

A good visual is not merely attractive. It performs one of these functions:

  1. Shows the concrete object being discussed.
  2. Simplifies an abstract concept into a metaphor.
  3. Creates emotional context for the listener.
  4. Clarifies numbers, relationships, or tradeoffs.
  5. Gives the audience a memory hook for a key point.

Bad visual direction:

Make a beautiful image about trucking economics.

Good visual direction:

Show a tired owner-operator sitting in a truck cab at night, looking at a clock and an unpaid detention invoice, while a warehouse loading dock glows outside the windshield. The image should communicate that waiting time destroys paid driving capacity.

Chapter 05

5. Style System

5.1 Style Selection Rule

The visual style is configurable. Select one of the numbered presets below, combine presets when useful, or create a custom style bible if the user asks for a direction not covered by the presets.

When recommending styles, refer to styles by their stable number and name. Choose based on topic, audience, emotional arc, and desired channel identity. Once chosen, the same style bible is copied into every image prompt in the sequence.

5.2 Style Slots (for custom styles)

If the user requests a style not in the library, fill this structure and use it as the style bible:

STYLE_NAME: "..."
MEDIUM: "..."
LINEWORK: "..."
COLOR: "..."
TEXTURE: "..."
MOOD: "..."
COMPOSITION: "clear focal point, uncluttered, 16:9"
EXCLUSIONS: "no photorealism, no 3D render, no anime, no logos"

5.3 Default Visual Traits (preset 01)

  • Format: horizontal 16:9 frame.
  • Mood: calm, analytical, documentary, reflective.
  • Linework: clean black or dark gray ink lines.
  • Color palette: muted cream, dusty blue, soft gray, warm brown, pale green, light ochre.
  • Texture: soft paper grain, watercolor wash, subtle hand-drawn imperfections.
  • Lighting: soft and natural, not dramatic unless the scene requires tension.
  • Composition: one clear focal point per frame.
  • Characters: simplified but adult and realistic; not cartoonish or childish.
  • Objects: desks, papers, maps, screens, clocks, invoices, tools, vehicles, rooms, charts.
  • Typography: avoid text inside AI images; use blank papers, generic labels, or overlays later.

5.4 Default Negative Prompt

Use or adapt this negative prompt unless the selected production tool requires another format:

photorealistic, 3D render, anime, childish cartoon, glossy, plastic, hyperreal, oversaturated colors, chaotic composition, unreadable text, misspelled text, fake letters, real brand logos, watermark, stock photo, cinematic action movie, distorted hands, extra fingers, deformed faces

Chapter 07

7. Workflow Overview

Follow this workflow every time:

  1. Read the full narration.
  2. Identify the topic, thesis, and emotional arc.
  3. Select the style preset (or custom style bible).
  4. Split the narration into beats every 6–10 seconds.
  5. Summarize each beat in one sentence.
  6. Choose a visual metaphor for each beat.
  7. Decide scene type: object close-up, character shot, environment shot, chart/diagram shot, transition shot.
  8. Write one image prompt per beat using the selected style bible.
  9. Add motion direction for video editing.
  10. Add text overlay separately if needed.
  11. Verify consistency across the whole sequence.

Chapter 08

8. Step-by-Step Procedure

Step 1: Analyze the Narration

Extract:

  • Topic.
  • Main thesis.
  • Key characters or institutions.
  • Repeated objects or motifs.
  • Core conflict.
  • Emotional tone.
  • Important numbers.
  • Places and time periods.

Output:

topic: "..."
thesis: "..."
main_characters: []
institutions: []
recurring_motifs: []
key_numbers: []
emotional_arc: "..."

Completion criterion: the AI can explain the video in 3–5 sentences before generating any image prompts.

Step 2: Select the Style

Recommend 2–3 numbered presets that fit the topic, audience, and emotional arc, then lock one:

selected_style: "01. Default 2D Hand-Drawn Editorial Explainer"
style_bible: "..."
negative_prompt: "..."

If the user supplies a custom direction, fill the Style Slots in §5.2 instead. The rest of the workflow is unchanged.

Completion criterion: exactly one style bible string is locked and will be copied into every prompt.

Step 3: Segment into Story Beats

Create one beat every 6–10 seconds by default.

Rules:

  • One beat = one visual idea.
  • Do not create a new image for every sentence.
  • Combine sentences when they express the same idea.
  • Split when the narration introduces a new object, number, actor, location, or emotional turn.

Recommended density:

Video length Typical images
3 minutes 20–35 images
5 minutes 35–60 images
10 minutes 70–120 images
20 minutes 120–220 images
30 minutes 180–320 images

Output fields:

beat_id: 001
timestamp_start: "00:00"
timestamp_end: "00:08"
narration_excerpt: "..."
beat_summary: "..."

Completion criterion: every part of the narration belongs to exactly one beat.

Step 4: Choose a Visual Function

For each beat, choose one visual function:

Function Use When Example
Concrete depiction The narration mentions a physical thing truck, chair, document, phone
Visual metaphor The concept is abstract money leaking from a pipe
Process diagram The narration explains a flow shipper → broker → driver
Emotional scene The beat is about stress, risk, unfairness person waiting under a clock
Number visualization The beat contains statistics stack of coins, bars, gauges
Contrast shot The beat compares two sides broker office vs driver cab
Establishing shot New location or chapter warehouse, city, office
Transition shot Bridge between sections road at dusk, papers sliding

Completion criterion: each beat has a clear visual function, not just a generic topic label.

Step 5: Create Visual Metaphors

For abstract concepts, use objects.

Abstract idea Visual metaphor
Hidden cost invoice partly under a desk shadow
Waiting time large wall clock over parked vehicle
Middleman spread money split across two hands
Legal constraint two overlapping clocks or gauges
Fragile profit margin thin coin balancing on a ruler
Scale advantage many routes converging into one hub
Unpaid labor blank paycheck next to work gloves
Opportunity cost road fading into a locked gate
Complexity desk covered with forms and wires
Risk storm cloud over a small business ledger

Completion criterion: every abstract beat has a concrete imageable metaphor.

Step 6: Build the Shot List

For each beat, create a shot list entry with these fields:

{
  "scene_id": "001",
  "timestamp_start": "00:00",
  "timestamp_end": "00:08",
  "narration_excerpt": "...",
  "core_idea": "...",
  "visual_function": "concrete depiction | visual metaphor | process diagram | emotional scene | number visualization | contrast shot | establishing shot | transition shot",
  "visual_description": "...",
  "selected_style": "01. Default 2D Hand-Drawn Editorial Explainer",
  "image_prompt": "...",
  "negative_prompt": "...",
  "motion_direction": "...",
  "text_overlay": "...",
  "continuity_notes": "..."
}

Completion criterion: the shot list can be handed to an image model operator without further explanation.

Step 7: Write Image Prompts

Use this image prompt template:

[SELECTED_STYLE_BIBLE]

Scene: [specific location]
Subject: [main object/person]
Action / idea: [what this image communicates]
Composition: [close-up / medium shot / wide shot / overhead / low angle]
Details: [props, environment, symbolic objects, time of day]
Mood: [calm / tense / analytical / reflective / urgent]
Lighting: [soft office light / dusk / morning / warehouse fluorescent]
Continuity: [same character/object/location notes]
Constraints: no real logos, no important readable text, leave space for overlays, 16:9.

Rules:

  • Be concrete. Name the objects in the frame.
  • Avoid vague words like "interesting", "beautiful", or "professional" unless paired with specifics.
  • Include camera composition.
  • Include props that carry the meaning.
  • Keep one focal idea per image.
  • Avoid important text inside the image.
  • Do not ask the image model to generate accurate charts or tiny labels. Add those later.

Completion criterion: the prompt describes exactly what should appear in the image and why.

Chapter 09

9. Consistency System

9.1 Visual Motifs

Pick 5–10 recurring motifs for the whole video. For business explainer content, common motifs include:

  • Desk with papers.
  • Invoice or bill.
  • Clock or timer.
  • Map or route line.
  • Computer dashboard.
  • Hands pointing at documents.
  • Coins, receipts, ledger books.
  • Warehouse or office interiors.
  • Vehicle, machine, factory, or infrastructure object.
  • Whiteboard diagrams.

Repeat these motifs across scenes so the video feels like one coherent world.

9.2 Character Continuity

If a recurring character appears, create a character bible before generating scenes.

character_name: "Main narrator subject"
age: "..."
body_type: "..."
hair: "..."
clothing: "..."
accessories: "..."
personality_visual: "..."
recurring_expression: "..."
do_not_change: ["hair", "clothing color", "face shape", "main accessory"]

Prompt block:

Recurring character: middle-aged independent truck driver, short brown hair, light stubble, navy work shirt, faded baseball cap, tired but focused expression, realistic simplified proportions, same character design in every scene.

If the image platform supports reference images, first generate:

  1. Character sheet.
  2. Object sheet.
  3. Color palette sheet.
  4. Key environment sheet.

Then use those as references for the whole batch.

9.3 Location Continuity

For repeated locations, define them once:

location_name: "Driver cab at night"
visual_traits: "dark dashboard, windshield view of warehouse lights, paper coffee cup, clipboard, soft blue-gray light"
recurring_props: ["dashboard", "clock", "clipboard", "coffee cup"]

9.4 Palette Continuity

Use one palette across the sequence:

palette:
  background: "warm off-white"
  linework: "dark charcoal"
  primary: "dusty blue"
  secondary: "muted ochre"
  accent: "soft red for warnings"
  neutral: "warm gray and brown"

Chapter 10

10. Text and Numbers Policy

AI image models often produce broken text. Therefore:

  • Do not ask for exact text inside generated images unless the model is known to handle typography well.
  • Use blank spaces, generic documents, empty charts, and symbolic numbers.
  • Add exact text later in the video editor.
  • Text overlays should be specified separately.

Use this field:

text_overlay: "$250,000 revenue → $64,000 take-home"

Instead of this inside the image prompt:

Write the exact words "$250,000 revenue → $64,000 take-home" on the document.

If text must appear inside the image, keep it short:

  • OK: "RATE", "TIME", "FUEL", "WAIT"
  • Avoid: long paragraphs, detailed tables, accurate forms, legal documents

Vertical pan Tall objects, stacks, hierarchy

Output example:

Chapter 12

12. Batch Generation Procedure

12.1 First Pass

Generate only 5–8 test images first:

  1. Establishing shot.
  2. Character shot.
  3. Object close-up.
  4. Diagram-like scene.
  5. Emotional scene.
  6. Number/statistic scene.
  7. Transition shot.
  8. Final question shot.

Review for style consistency, character consistency, prompt clarity, text mistakes, color palette, and whether the images feel like the same video.

12.2 Lock Style

Once the test batch works, lock:

  • Style bible (with its preset number).
  • Palette.
  • Character references.
  • Main environments.
  • Negative prompt.
  • Aspect ratio.
  • Seed or style reference if available.

12.3 Generate Full Batch

Generate in chunks of 10–20 images. After each chunk, check:

  • Does the style drift?
  • Are characters changing faces or clothing?
  • Are props accurate enough?
  • Are any images too literal or too abstract?
  • Are any images too cluttered?
  • Is there unwanted text?
  • Are there logos or copyrighted marks?

Regenerate weak images immediately before continuing.

Chapter 13

13. Quality Control Checklist

For each image, answer:

  • Does it represent the assigned beat?
  • Is there one clear focal point?
  • Is the composition readable in 2–3 seconds?
  • Does it match the selected style bible?
  • Are the colors consistent with the series?
  • Are recurring characters and objects consistent?
  • Is there any broken text?
  • Are there any brand logos or copyrighted marks?
  • Are hands, faces, and object proportions acceptable?
  • Does it leave room for subtitles or overlays if needed?
  • Does the image support the narration rather than distract from it?

Classify each image:

status: pass | minor_fix | regenerate
reason: "..."

19. Common Pitfalls

  1. Too decorative: The image is attractive but does not explain the narration.
  2. Too literal: Every sentence becomes a direct object, making the video boring.
  3. Style drift: Each generated image looks like a different project.
  4. Character drift: The same person changes face, age, clothing, or body type.
  5. Broken text: AI-generated documents contain unreadable fake writing.
  6. Too much detail: The viewer cannot understand the image in a few seconds.
  7. No visual rhythm: Every shot has the same distance and composition.
  8. No recurring motifs: The sequence lacks identity.
  9. Overuse of diagrams: The video feels like slides instead of a story.
  10. Underuse of diagrams: Abstract financial or system concepts remain unclear.
  11. Wrong mood: A serious documentary topic becomes too cute or flashy.
  12. Ignoring edit needs: No room for subtitles, overlays, or motion.
  13. Mixing presets accidentally: Different scenes silently use different style bibles.
